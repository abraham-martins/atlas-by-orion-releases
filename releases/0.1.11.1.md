# ATLAS by Orion 0.1.11.1 Stable

**Build:** 001B Part 02 — Stable Update Test  
**Canal:** Stable  
**Data:** 16/09/2026

Esta versão será usada para validar o atualizador automático do ATLAS de ponta a ponta.

## Principais mudanças

- atualização automática pelo GitHub Releases;
- download com progresso;
- validação SHA-256 antes da instalação;
- backup completo antes do update;
- novos controles de janela ATLAS para minimizar, maximizar/restaurar e fechar;
- preservação de configurações, SQLite, favoritos, projetos, histórico e backups.

O instalador será anexado à Release `v0.1.11.1` antes de o `stable-feed.json` ser promovido para esta versão.
